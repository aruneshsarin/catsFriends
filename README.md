# Cats Friends

A tiny React project from my early web-dev learning days.

This repo started as a playground for core frontend concepts:
- components and props
- state and controlled inputs
- API calls and rendering dynamic lists
- CSS layout practice with cards and grid

## Why I keep this project

This app reminds me what "learning in public" feels like: small wins, typos, rough edges, and momentum.
I am intentionally keeping the spirit of the original code while making only light upgrades over time.

## Small upgrades added

- Better project readme and learning story
- Safer data fetching flow with loading + error states
- Fixed case-sensitive import (`./App`) for better cross-platform reliability
- Slight UI refresh with responsive grid and softer page styling

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000
